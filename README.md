# Windows 10 Web 🪟

سطح مكتب **ويندوز ١٠** كامل بيشتغل في المتصفح — مبني بالكامل بـ HTML و CSS و JavaScript خالص، بدون أي مكتبات خارجية.

## التشغيل

```bash
npm start
# أو
node server.js
```

بعدها افتح: **http://localhost:3000**

(لو البورت مش فاضي، السيرفر هيختار واحد تاني لوحده ويطبعلك الرابط)

بدون Node؟ أي سيرفر ملفات ثابتة يكفي، مثلًا:

```bash
python3 -m http.server 3000 -d public
```

## المميزات

- 🔵 **تسلسل إقلاع كامل**: شاشة Boot بشعار ويندوز → شاشة قفل → تسجيل دخول → سطح المكتب
- 🪟 **مدير نوافذ حقيقي**: سحب، تحجيم من كل الجهات، تصغير/تكبير، وإلصاق النوافذ على حواف الشاشة (Snap: فوق = تكبير، يمين/شمال = نص شاشة)
- 📋 **قائمة ابدأ**: قائمة تطبيقات أبجدية + Live Tiles + أوامر الطاقة (إطفاء/إعادة تشغيل/سكون)
- 🔍 **بحث** في شريط المهام + **Task View** بمعاينات مصغّرة حقيقية للنوافذ
- 🔔 **مركز الصيانة**: إشعارات + Night Light حقيقي + مؤشر سطوع شغّال
- 📁 **نظام ملفات وهمي** محفوظ في المتصفح (localStorage) — الملفات اللي تعملها بتفضل موجودة
- ⚙️ **إعدادات**: تغيير الخلفية، لون النظام (Accent)، الوضع الليلي، تلوين شريط المهام

### التطبيقات

| التطبيق | الوصف |
|---|---|
| File Explorer | مستكشف ملفات متصل بالنظام الوهمي (إنشاء/حذف/إعادة تسمية) |
| Edge | متصفح حقيقي بتبويبات — المواقع اللي تسمح بالتضمين هتشتغل جواه |
| Notepad | مفكرة ب Save/Open فعلي في نظام الملفات |
| Calculator | آلة حاسبة كاملة بلوحة مفاتيح |
| Paint | رسم بقلم وأشكال وحفظ في Pictures |
| Command Prompt | تيرمنال بأوامر حقيقية: `dir`, `cd`, `type`, `tree`, `start notepad`, `color 0a`, `shutdown`… |
| Task Manager | عمليات حية + رسوم بيانية CPU/RAM متحركة + End Task |
| Minesweeper | كانسة ألغام كلاسيكية ٩×٩ |
| Photos | عارض صور يشوف رسوماتك من Paint |
| Recycle Bin | سلة محذوفات باستعادة وحذف نهائي |

## لمسات مفيدة

- روابط النوافذ على حواف الشاشة للـ Snap
- زر ديليت أو Enter على أيقونات سطح المكتب
- كليك يمين على كل حاجة تقريبًا (سطح المكتب، الملفات، أزرار شريط المهام)
- `#skip` بعد الرابط يقفز مباشرة لسطح المكتب (مفيد للتطوير): `http://localhost:3000/#skip`
- كل حاجة محفوظة في localStorage — من الإعدادات صفحة Apps تقدر ترجّع نظام الملفات لوضعه الأصلي

## البنية

```
server.js            سيرفر ثابت بدون أي اعتماديات
public/
  index.html
  css/               base, desktop, taskbar, window, apps
  js/
    main.js          تسلسل الإقلاع
    wm.js            مدير النوافذ
    fs.js            نظام الملفات الوهمي
    settings.js      الإعدادات والثيمات
    desktop.js       أيقونات سطح المكتب
    startmenu.js     قائمة ابدأ
    taskbar.js       شريط المهام واللوحات
    ui.js            قوائم/حواريات/إشعارات
    icons.js         أيقونات SVG مرسومة يدويًا
    apps/            التطبيقات (explorer, notepad, edge, paint, …)
```
