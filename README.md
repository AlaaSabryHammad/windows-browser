# Windows 10 Web 🪟

جهاز **ويندوز ١٠** كامل بيشتغل في المتصفح — مش مجرد شكل: نظام ملفات حقيقي بيتحفظ، حسابات بباسورد، اختصارات كيبورد، كاميرا، ميديا، طقس حقيقي… كله مبني بـ HTML و CSS و JavaScript خالص، بدون أي مكتبات خارجية وبدون build.

## التشغيل

```bash
npm start
# أو
node server.js
```

بعدها افتح: **http://localhost:3000**

(لو البورت مش فاضي، السيرفر هيختار واحد تاني لوحده ويطبعلك الرابط)

بدون Node؟ أي سيرفر ملفات ثابتة يكفي، مثلًا:

```bash
python3 -m http.server 3000 -d public
```

> الكاميرا ولقطة الشاشة محتاجين "سياق آمن": افتحه على `localhost` أو `https://`.

## إحساس جهاز حقيقي

- 🔵 **إقلاع كامل**: Boot ← إعداد أول مرة (اسمك، باسورد، الثيم واللون) ← شاشة قفل ← تسجيل دخول بصوت ← سطح المكتب
- 🔐 **حساب بباسورد حقيقي** (مخزّن كـ SHA-256 مع تلميح)، قفل، تسجيل خروج بيقفل كل البرامج، سكون، إطفاء، وإعادة تشغيل — ولو فيه ملف مش متحفظ، الويندوز بيسألك قبل ما يقفل
- ⌨️ **اختصارات الكيبورد**: `Win` / `Ctrl+Esc` قائمة ابدأ، `Win+E` المستكشف، `Win+R` تشغيل، `Win+D` سطح المكتب، `Win+I` الإعدادات، `Win+L` قفل، `Win+A` مركز الصيانة، `Win+Tab`، `Win+X`، `Win+←→↑↓` لإلصاق النوافذ، `Win+1..9`، `Alt+Tab` (أو ``Alt+` `` جوه المتصفح)، `Alt+F4`، `Ctrl+Shift+Esc`، `Ctrl+Alt+End` (شاشة الأمان)، `PrintScreen` لقطة شاشة
- 🖥️ **ملء الشاشة + قفل الكيبورد**: عند تسجيل الدخول بيدخل Full screen ويقفل الكيبورد (Keyboard Lock API) عشان زرار Win و Alt+Tab يشتغلوا فعلًا جوه الويندوز (ممكن تقفلها من الإعدادات)
- 🔊 **أصوات النظام** متولّدة بـ Web Audio: تسجيل الدخول، الإشعارات، الأخطاء، تفريغ سلة المحذوفات، المنبّه — ومعاها مؤشر صوت وكتم حقيقيين
- 📊 **بيانات حقيقية من جهازك**: البطارية (Battery API)، حالة الشبكة وسرعتها، عدد المعالجات والرام والشاشة في "About"، المساحة المتاحة فعلًا للتخزين، وحِمل المعالج/الذاكرة/القرص/الشبكة في Task Manager

## سطح المكتب والنوافذ

- مدير نوافذ: سحب، تحجيم من كل الجهات، Snap للنص وللأرباع (اسحب للحواف والأركان)، النوافذ بتفتكر مكانها وحجمها، قائمة النظام من أيقونة النافذة، ونوافذ متكيّفة مع تغيير حجم المتصفح
- أيقونات سطح المكتب: تتحرك بحرية وتتحفظ أماكنها، تحديد متعدد، إعادة تسمية في مكانها (`F2`)، `Delete` / `Shift+Delete`، `Ctrl+C/X/V/A`، أحجام كبيرة/متوسطة/صغيرة، ترتيب
- **اسحب ملفات من جهازك الحقيقي** على سطح المكتب أو المستكشف وهتتنسخ جوه الويندوز (حتى فولدرات كاملة) — واسحب ملف من الويندوز لبرة يتحفظ على جهازك
- شريط المهام: معاينات حيّة للنوافذ، تثبيت/إلغاء تثبيت التطبيقات، بحث في التطبيقات والإعدادات **والملفات**، Task View، تقويم، مركز صيانة بإشعارات قابلة للضغط وأزرار سريعة (Night light، Airplane، Focus assist، Full screen، Dark mode…)
- قائمة ابدأ: Live Tiles حيّة (ساعة، طقس، صور، ملاحظات، الأغنية الشغالة)، تثبيت وتغيير أحجام البلاطات، "الأكثر استخدامًا"، مجلد Windows System، والكتابة وهي مفتوحة بتبحث

## نظام الملفات

- قرص `C:` وهمي **محفوظ في IndexedDB** (مساحة كبيرة — مش 5MB بتاعة localStorage)، والنسخة القديمة بتتنقل لوحدها
- مسارات ويندوز حقيقية (`C:\Users\User\Documents`، `..`، حروف كبيرة/صغيرة)، نسخ/قص/لصق، سحب وإفلات، سلة محذوفات بتحفظ المكان الأصلي
- نافذة Open / Save As حقيقية في كل البرامج

## Word و Excel

ملفات **`.docx` و `.xlsx` حقيقية** — نزّلها من الويندوز وافتحها في Microsoft Office أو LibreOffice أو Google Docs، والعكس: ارفع ملفاتك وافتحها هنا (القراءة والكتابة مكتوبين من الصفر بدون أي مكتبات).

**Word**
- شريط Ribbon (File / Home / Insert / Layout / View): خطوط وأحجام، عريض/مائل/تحته خط/يتوسطه خط، أُس وأسفل، ألوان وتظليل، قوائم نقطية ورقمية، محاذاة، تباعد الأسطر، وكتابة من اليمين لليسار للعربي
- معرض أنماط (Normal، Title، Heading 1-3، Quote)، وEnter بعد العنوان يرجع Normal زي وورد
- إدراج جداول (مع قائمة صف/عمود/تظليل)، صور من جهازك أو من الـ C:، روابط، فاصل صفحة، تاريخ ورموز
- هوامش واتجاه الصفحة، بحث واستبدال، عدد الكلمات، تكبير، وضع التركيز، قوالب (خطاب، سيرة ذاتية، تقرير)
- حفظ بصيغة `.docx` أو `.html` أو `.txt`، وطباعة / PDF

**Excel**
- معادلات بمحرّك حقيقي: `SUM`، `AVERAGE`، `IF`، `VLOOKUP`، `INDEX`/`MATCH`، `SUMIF`، `COUNTIF`، `TODAY`، نصوص وتواريخ وأكتر — مع مراجع بين الشيتات وأخطاء زي `#DIV/0!` و `#REF!` وكشف المراجع الدائرية
- تحديد بالماوس والكيبورد، Fill handle بيكمّل الأرقام والشهور والأيام وبيزحلق المعادلات، نسخ/لصق متوافق مع Excel الحقيقي، تراجع/إعادة
- تنسيقات: عملة، نسبة، تاريخ، وقت، خلايا ملونة، التفاف النص، عرض الأعمدة
- إدراج/حذف صفوف وأعمدة مع تصحيح المراجع، ترتيب، إزالة التكرار، AutoSum، نافذة Insert Function
- رسوم بيانية (أعمدة، أشرطة، خطوط، دائرية) بتتحدث لحظيًا وتقدر تحركها وتحفظها صورة
- شيتات متعددة (إضافة/حذف/إعادة تسمية/ترتيب)، تجميد الصف الأول، تكبير، والمتوسط/العدد/المجموع في شريط الحالة
- فتح وحفظ `.xlsx` و `.csv`

تلاقي ملفين جاهزين في **Documents** تجربهم (`Welcome to Word.docx` و `Budget.xlsx`)، وكليك يمين ← **New** بيعمل مستند أو جدول جديد، ومن الـ Command Prompt: `winword` أو `excel Budget.xlsx`.

## التطبيقات

| التطبيق | الوصف |
|---|---|
| File Explorer | شريط عنوان قابل للكتابة، عرض أيقونات/تفاصيل وترتيب بالأعمدة، بحث داخل الفولدرات، تحديد متعدد، رفع وتنزيل من/إلى جهازك، خصائص |
| Microsoft Edge | تبويبات، مفضلة وسجل، Bing/Google/Wikipedia جوه الويندوز، فيديوهات يوتيوب، فتح ملفات `file:///C:/…`، وصفحة واضحة للمواقع اللي بترفض التضمين |
| Command Prompt | `cd \Users`، `dir`، `mkdir`، `del *.txt`، `copy`، `move`، `ren`، `type`، `find`، `echo … > ملف`، `set`/`%VAR%`، `tasklist`، `taskkill`، `ping` حقيقي، `ipconfig`، `systeminfo`، `shutdown /r /t 10`، إكمال بـ Tab |
| Word · Excel | شوف القسم اللي فوق ☝️ |
| Notepad | فتح/حفظ في أي مكان، بحث واستبدال، Go To، Word wrap، تكبير، طباعة، وسؤال "حفظ التغييرات؟" |
| Paint | قلم، فرشاة، ممحاة، تعبئة، قطّارة ألوان، نص، أشكال (مملوءة)، تراجع/إعادة، فتح وحفظ صور، لصق صور من الحافظة، تدوير وقلب، تعيين كخلفية |
| Photos | يعرض صور نفس الفولدر، تكبير بالعجلة وسحب، تدوير، عرض شرائح، حذف، تعديل في Paint، تعيين كخلفية |
| Media Player | مكتبة موسيقى وفيديو، قوائم تشغيل، عشوائي/تكرار، Visualizer، وأزرار الميديا في الكيبورد |
| Camera | الكاميرا الحقيقية: صور وفيديو بيتحفظوا في Camera Roll، مؤقت، مرآة، تبديل الكاميرات |
| Alarms & Clock | منبهات بترن حتى لو البرنامج مقفول، مؤقتات، ساعة إيقاف بلفّات، ساعة عالمية |
| Weather | طقس حقيقي من Open-Meteo لموقعك أو أي مدينة، بالساعة ولسبع أيام |
| Sticky Notes | كل ملاحظة نافذة لوحدها بألوان، وبتفضل محفوظة |
| Task Manager | عمليات، أداء حي (CPU/Memory/Disk/Wi-Fi)، برامج بدء التشغيل، تفاصيل، End task |
| Settings | النظام، التخزين، التخصيص (خلفية من صورك أو لون)، التطبيقات، الحسابات والباسورد، الوقت، التحديثات، إعادة ضبط الجهاز، ومواصفات جهازك الحقيقية |
| Run · Calculator · Minesweeper · Recycle Bin | `Win+R` بأوامر حقيقية، آلة حاسبة بنسخ/لصق، كانسة ألغام بثلاث مستويات وأفضل أوقات |

## لمسات مفيدة

- `#skip` بعد الرابط يقفز مباشرة لسطح المكتب (مفيد للتطوير): `http://localhost:3000/#skip`
- من الإعدادات ← Update & Security ← **Reset this PC** بترجع الجهاز لحالة المصنع وتشغّل الإعداد الأول من جديد

## البنية

```
server.js              سيرفر ثابت بدون أي اعتماديات
public/
  index.html
  css/                 base, desktop, taskbar, window, apps, shell, office
  js/
    main.js            الإقلاع، الإعداد الأول، القفل، الإطفاء والسكون
    shell.js           اختصارات الكيبورد، Alt+Tab، شاشة Ctrl+Alt+Del
    wm.js              مدير النوافذ (Snap، حفظ الأماكن، منع القفل مع ملفات غير محفوظة)
    fs.js              نظام الملفات (IndexedDB)
    fileops.js         فتح، نسخ/قص/لصق، سحب وإفلات، رفع وتنزيل، خصائص
    filedialog.js      نافذة Open / Save As
    settings.js        الإعدادات والحساب
    sound.js           أصوات النظام (Web Audio)
    desktop.js         سطح المكتب
    startmenu.js       قائمة ابدأ
    taskbar.js         شريط المهام واللوحات
    ui.js              قوائم/حواريات/إشعارات
    icons.js           أيقونات SVG مرسومة يدويًا
    apps/              التطبيقات (منها word.js و excel.js)
    office/            zip، قراءة/كتابة docx و xlsx، محرّك المعادلات، الرسوم البيانية
```

مش تابع لمايكروسوفت — إعادة بناء حبًا لِتجربة ويندوز ١٠. انسخه كما تشاء.
